# 指スマBotの仕様メモ

更新日: 2026-09-23

## ユーザーが指定した内容

- Discordのパネルで指スマを遊ぶ。
- 1人プレイはCPUとの対戦、2人プレイはプレイヤー同士の対戦。
- 初期パネルのボタンは「プレイ開始」「ルール説明」「残高確認」。
- 「プレイ開始」を押すと、1人プレイか2人プレイを選択する。
- 2人プレイでは、両プレイヤーがお互いを対戦相手として選択する。
- 相互選択が成立したらマッチングし、指スマを開始する。
- 設置先はLEVELIAのカジノカテゴリーを予定。パネルはまだ設置しない。
- Railway / TypeScript / MySQLを採用する。
- 対象サーバーの `GUILD_ID` はRailwayの環境変数で設定する。
- 既存LEVELIA Botとはリポジトリを分け、`LEVELIA_GAME` としてGitHubでPublic管理する。

## 実装時の候補（未確定）

- カジノカテゴリー内のテキストチャンネルに入口パネルを置く。対象チャンネルは未指定。
- 対戦相手の選択はDiscordのUser Selectで行う。
- 指の入力は本人だけが見える応答で受け付け、両者の入力が揃ってから結果を公開する。
- マッチングとゲーム進行をMySQLに保存し、二重マッチや二重入力を防ぐ。
- コードとデプロイを独立させ、既存Botとの通貨連携は別途設計する。

## まだ決まっていないこと

- 指の本数、宣言の順番、勝敗条件などの詳細ルール。
- CPUの判断方法、難易度。
- 制限時間、キャンセル、切断・再起動時の扱い。
- 残高の通貨と用途。既存LIA残高を共有するか、賭け金・報酬を設けるか。
- Discordアプリ、設置チャンネルID、Railwayプロジェクト、DB接続先。

## 現在の実装範囲

TypeScriptの開発・ビルド設定、環境変数チェック、MySQL接続確認、Discord接続用の起動処理、Railway設定、CIのみ。
パネル、マッチング、ゲーム処理、残高機能、DBテーブル、スラッシュコマンドは未実装。
