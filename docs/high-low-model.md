# ハイ＆ロー 新しい配当モデルについて

運用の基準は**目標平均還元率100%**とします。カードと予想方向の勝率に応じて配当を計算し、連勝するほど配当計算が有利になる仕組みです。運営側で目標還元率を変更できます。

以下は目標100%での説明です。現在の本番設定を示すものではありません。

## 1. 配当の計算方法

受取額は、次の式で計算します。

```text
受取額 ＝ 賭け金 × 累積倍率 × 精算時の還元係数
```

受取額には元の賭け金を含み、最後に1 LIA未満を切り捨てます。

### 勝率から倍率を求める

累積倍率は1倍から始まり、勝つたびに「1 ÷ その勝負の勝率」を掛けます。当たりやすい選択ほど低倍率、当たりにくい選択ほど高倍率になります。

```text
1勝時の累積倍率 ＝ 1 ÷ 1勝目の勝率
2勝時の累積倍率 ＝ (1 ÷ 1勝目の勝率) × (1 ÷ 2勝目の勝率)
```

### 連勝数に応じた還元係数

目標100%の場合、精算時に使う係数は次のとおりです。

| 精算する連勝数 | 還元係数 |
| --- | ---: |
| 1連勝 | 約97.00% |
| 2連勝 | 約97.97% |
| 3連勝 | 約98.95% |
| 4連勝 | 約99.92% |
| 5連勝 | 約100.90% |

この係数は、**精算する連勝段階のものを1回だけ**使います。勝つたびに還元係数まで掛け続ける計算ではありません。

表は表示用に丸めた値です。実際の配当計算では、丸める前の係数を使います。

### 1,000 LIAを賭けた場合の例

カード8でHIGHを選び、1勝して精算する場合：

```text
1,000 × (1 ÷ 0.5005) × 0.96996381
＝ 約1,937.99

受取額：1,937 LIA
利益：937 LIA
```

2回とも基準カードが8の勝負に勝ち、2連勝で精算する場合：

```text
1,000 × (1 ÷ 0.5005) × (1 ÷ 0.5005) × 0.97971219
＝ 約3,911.02

受取額：3,911 LIA
利益：2,911 LIA
```

### 目標還元率を配当に反映する仕組み

補正前の基準連勝係数は99.5 → 100.5 → 101.5 → 102.5 → 103.5%です。この状態での基準行動モデルの推定平均還元率は約102.5812%でした。

目標100%では、配当全体に以下の補正を掛けます。

```text
補正係数 ＝ 目標(%) ÷ 102.58118179645447
目標100%の補正係数 ＝ 0.974838（小数点以下6桁に丸める）
精算時の還元係数 ＝ 基準連勝係数 × 補正係数
```

例えば1勝では `99.5% × 0.974838 ＝ 96.996381%`。目標を変える場合も全段階を同じ割合で補正するため、連勝するほど有利になる構造は維持されます。

## 2. 以前からの変更点

| 項目 | 以前のモデル | 新しいモデル |
| --- | --- | --- |
| 配当倍率 | 1〜5連勝で1.5／2／3／4／6倍に固定 | カード・HIGH／LOWの選択・連勝数で変化 |
| 選択の難しさ | 同じ連勝数なら、当たりやすさに関係なく同じ配当 | 当たりにくい選択ほど、勝った場合の配当が高い |
| 画面の配当表示 | 連勝数ごとの固定配当 | HIGH／LOWに次の勝利時の受取額、精算ボタンに現在の受取額を表示 |
| 運営による調整 | 固定配当の設定に依存 | コマンドで目標平均還元率を指定し、配当全体を補正 |

賭け金100／1,000／10,000 LIA、1勝からの途中精算、5連勝での自動精算、外れた場合の払い戻しなし、同じ数字での引き分けは共通です。新モデルの5連勝時の配当は、固定の6倍ではありません。

## 3. 運営用コマンド

現在の設定を確認：

```text
/ハイロー還元率 確認
```

目標を100%に設定：

```text
/ハイロー還元率 設定 目標:100
```

98%や101%に変更する場合：

```text
/ハイロー還元率 設定 目標:98
/ハイロー還元率 設定 目標:101
```

- 利用できるのは「英傑・皇帝・システム支配人」の3ロールです。
- 確認時には目標値、基準行動モデルでの推定還元率、補正係数、各連勝の還元係数などを表示します。
- 応答は実行した本人だけに表示されます。
- 変更は新しく開始するゲームから適用され、進行中のゲームは開始時の設定を維持します。
- 設定と変更履歴は保存され、再起動後も維持されます。

「未指定」と表示される場合は、補正係数1の基準配当です。**未指定と目標100%は異なります。** 100%を基準に運用する際は、明示的に100を設定します。

## 4. 実際にどの程度の期待還元率になるか

**目標100%で再試算した結果、基準のプレイヤー構成では期待還元率は約100.003%でした。** ただし、これは行動を仮定したシミュレーション上の期待値で、本番プレイヤーの実測値ではありません。

```text
還元率 ＝ 払い戻し総額 ÷ 賭け金総額 × 100
```

### プレイヤー構成ごとの試算

目標100%、同じ基準行動の条件で、プレイヤーの構成を変えた結果です。

| 想定するプレイヤー構成 | 推定期待還元率 |
| --- | ---: |
| 慎重な人が多い | 約99.62% |
| 中間・目標利益型が多い（設定の基準） | 約100.003% |
| 6タイプを同人数ずつ | 約100.27% |
| 続行する人・期待値重視の人が多い | 約100.54% |

構成に加えて「全体的に早く精算する／続けやすい」という行動差も変えた12通りでは、**約99.25〜100.67%**でした。この範囲は検証した条件の範囲であり、実運用で必ず収まる上下限ではありません。

### 5連勝まで続ける場合

途中精算をせず、原則5連勝まで続ける「期待値重視型」単独では、試算上の期待還元率は**約100.89%**でした。口座上限と整数切り捨てを無視した場合の5連勝固定精算の理論値も、5連勝の還元係数である約100.8957%になります。

つまり、**目標100%は「想定するプレイヤー全体で約100%」に合わせる設定であり、すべての遊び方を100%以下にする設定ではありません。** 早めの精算と5連勝までの続行では、期待還元率が異なります。

### 試算条件と実測値の扱い

- 2026年10月3日に、目標100%の補正係数0.974838で再実行。感度分析を含めて36,000セッション・3,572,934ゲームを計算しました。
- 利益保全・バランス・目標利益・損失回復・高配当志向・期待値重視の6タイプを仮定。精算タイミング、残高、損益による行動変化などをモデル化しています。
- 還元率は人数の単純平均ではなく、賭け金総額で重み付けしています。まれな高額配当も評価するため、期待値の推定には重要度サンプリングを使っています。
- 基準構成の推定値は約100.003%、統計的な95%区間は約99.988〜100.018%。この区間には、仮定した人の行動と現実のずれは含まれません。
- 同じ基準構成で通常抽選の払い戻しを集計した今回のシミュレーション実現値は約99.86%でした。有限回の結果は期待値と一致しません。
- 実際の利用者データに適合させた行動モデルではありません。また、試算では次の配当が口座上限を超える場合に精算するなどの行動を仮定しています。本番では該当する選択を拒否するため、その後の利用者の行動次第でも差が出ます。

本番の実測還元率は、運用後の賭け金・払い戻しの台帳で別途確認します。集計時は対象期間を明記し、未精算ゲームの賭け金だけを含めて還元率を低く見せないよう、完了したゲームに対応する賭け金と払い戻しで比較します。
